# Security

This repository holds a vocabulary and the small Python checks that validate it; it runs no service and handles no
data. The checks run only in CI and on a contributor's machine.

If you find a problem that could affect consumers — for example a check that can be made to run code from a crafted
file — report it privately through GitHub's security advisory feature for this repository ("Report a vulnerability")
rather than in a public issue. You will get an acknowledgement, and a fix lands as an ordinary release.

Problems with the vocabulary itself (a wrong definition, a missing term) are not security matters: open an issue or a
pull request.
